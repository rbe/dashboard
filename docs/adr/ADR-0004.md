# The app ships as a container image through the Make contract

## Rule

The app ships as the image `ghcr.io/rbe/dashboard`. `.github/workflows/ci.yml` calls only `make` targets, and `docs/pipeline-rules.md` lists the divergences from `r-github-pipeline`. `make build` also builds and smokes the Linux binary, which is not published. `scripts/render-docs.mjs` renders `docs/` for `make docs`. The npm package, the image, and the binary contain the built app only, not `.claude/`, `CLAUDE.md`, `docs/`, or the private board. `scripts/workflows.test.mjs` checks the workflow and the Makefile against this contract.

## Why

A laptop and CI run the same targets, so a local run proves the CI run. A GitHub release of the app and a public npm package were not chosen. The name `dashboard` on the public npm registry belongs to another package.
