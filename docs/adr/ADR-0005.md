# Vitest selects the tests of make test-changed

## Rule

`make test-changed` runs `vitest related --run` with the changed source files of `build/coverage/changed.txt`. `make coverage` writes `build/coverage/lcov.info` with Vitest and gives it to diff-cover. It writes no coverage map.

## Why

The workers of Vitest write no V8 coverage, so `node_cover_map.py` of `project-report` cannot map a test to the files it ran. Vitest knows the module graph and selects each test that imports a changed file. A move to `node --test` was not chosen, because 14 test files use the Vitest API.

## Divergence

Rule of the `node` skill: `COVERAGE_CMD` runs `node_cover_map.py` and `test-changed` selects tests from that map. Here: Vitest selects the tests. Why: Vitest writes no V8 coverage per test file.
