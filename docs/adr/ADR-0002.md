# shared/openapi.json is the contract of the HTTP API

## Rule

`shared/openapi.json` is the contract of `GET` and `PUT /api/dashboard`. The server checks each request and each response with `shared/validate.mjs`. `npm run generate` writes `shared/schema.ts` from the contract. The package `@rbe/dashboard-client` in `client/` calls only the routes of the contract. A change to a route changes the contract, the server, and the client in the same change.

## Why

A depending app installs the typed client from GitHub Packages. One contract file keeps the server, the UI, and the client on the same shapes. Hand-written types on each side were not chosen, because they drift.
