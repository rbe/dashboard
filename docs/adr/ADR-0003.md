# The server listens on localhost over HTTPS with a self-signed certificate

## Rule

The `dashboard` command listens on `127.0.0.1` and port 4173 unless `--host`, `--port`, or `PORT` says otherwise. The server speaks HTTPS only. It uses `data/tls/cert.pem` and `data/tls/key.pem`, creates the pair when it is missing, and replaces an expired pair. `--cert` and `--key`, or `DASHBOARD_TLS_CERT` and `DASHBOARD_TLS_KEY`, select other files. The server serves only files below the UI build directory. The API has no authentication. Only the container image sets `--host 0.0.0.0`, and `make run` publishes the port on `127.0.0.1` only.

## Why

The board is private to one machine. A listener on localhost keeps other hosts out without a login. HTTPS was chosen so that the browser treats the page as a secure context.
