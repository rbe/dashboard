# The board is one Markdown file on this machine

## Rule

The board is one Markdown file. The default is `data/dashboard.md`. `DASHBOARD_FILE` or `--file` selects another file. `src/markdown.ts` parses the file into systems and serializes the systems back to Markdown. The UI changes the systems in the browser, and `PUT /api/dashboard` replaces the whole file. A bookmark import adds systems to the same board. The repository does not commit `data/`, except `data/dashboard.example.md`.

## Why

The owner edits the board by hand and reads it without the app. A database or a second file format was not chosen, because the board is small and private to one machine.
